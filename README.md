# Редактор мокапов устройств

Локальный 3D-редактор для iPhone, Android, iPad, Mac, монитора и Apple Watch: загрузите изображение на экран, вставьте его из буфера обмена или по ссылке на сайт либо фрейм Figma, настройте ракурс и сохраните PNG. Файлы и вставленные картинки обрабатываются в браузере и не отправляются на серверы сторонних сервисов.

## Запуск

Нужен Node.js 24. При первом запуске после клонирования выполните `npm ci` в папке проекта.

Дважды нажмите `Запустить.cmd`. Скрипт откроет редактор в браузере. Пока работает редактор, оставьте окно запуска открытым; для остановки нажмите Ctrl+C в этом окне. Если редактор уже запущен, откроется существующий экземпляр.

Для разработки:

```powershell
npm run dev
```

Адрес: http://127.0.0.1:3000. Нужен современный браузер с WebGL 2. Для сборки и проверки:

```powershell
npm run typecheck
npm test
npm run build
```

Браузерные проверки используют установленный Microsoft Edge.

## Деплой на Vercel

Импортируйте GitHub-репозиторий как новый проект. Параметры:

- Framework Preset: **Next.js**.
- Root Directory: корень репозитория (`./`).
- Build Command: `npm run build`.
- Install Command: `npm ci`.
- Output Directory: оставьте значение по умолчанию для Next.js.
- Node.js: **24.x**, закреплена в `package.json`.

База данных не требуется. Модели GLB и шрифт лежат в `public` и входят в поставку. Скриншоты, проекты и PNG обрабатываются в браузере пользователя, серверного хранилища нет.

Единственная серверная функция — `/api/capture`: она снимает сайт по ссылке в headless Chromium из пакета `@sparticuz/chromium`. Отдельно настраивать её не нужно; на Vercel ссылки на адреса внутренней сети отклоняются.

Необязательная переменная окружения:

- `FIGMA_TOKEN` — персональный токен Figma (Settings → Security → Personal access tokens, доступ `File content: Read`). Нужен только для вставки по ссылке на фрейм Figma. Без него вставка картинки из Figma через буфер обмена работает. Локальный скрипт `Запустить.cmd` для деплоя не используется.

Next.js поддерживается Vercel без отдельного `vercel.json`: [документация Next.js на Vercel](https://vercel.com/docs/frameworks/full-stack/nextjs). Выбор Node.js через `engines` описан в [документации Vercel](https://vercel.com/docs/functions/runtimes/node-js/node-js-versions).

## Работа со сценой

- Сверху посередине — переключатель режимов «Изображение» и «Анимация». В изображении результат — PNG, в анимации — ролик; сцена и ключи при переключении сохраняются. Режим не входит в файл проекта; проект с анимацией открывается сразу в анимации.
- Справа — навигация по категориям «Устройство», «Камера», «Сцена» и, в режиме ролика, «Анимация». Внутри категории разделы раскрываются независимо; их состояние запоминается в браузере и не входит в проект. Выбор ключей или участка показывает применимые настройки анимации. Блок экспорта закреплён внизу панели.
- Меню «Модель» сгруппировано: iPhone (15 Pro и 15 Pro Max в цветах Black, White, Blue и Natural Titanium, 17 Pro и 17 Pro Max в цветах Cosmic Orange, Deep Blue и Silver, 18 Pro и 18 Pro Max в цветах Black, Glacier, Burgundy и Silver, складной iPhone Duo), Android (Galaxy S26 Ultra), iPad (iPad Pro 13″ в цветах Silver и Space Black), Mac (MacBook Air 13″, MacBook Pro 14″, iMac 24″), «Дисплеи» (Pro Display XDR) и «Часы» (Apple Watch Ultra 2 и Series 9). Названия моделей соответствуют метаданным файлов, авторы — в `THIRD_PARTY_NOTICES.md`.
- У iPhone Duo есть ползунок «Раскрытие телефона» от 0° (сложен) до 180° (раскрыт). От 90° и выше изображение выводится на внутренний экран, ниже — на внешний, и модель поворачивается к камере нужной стороной. Проекты со старыми положениями «Раскрыт», «Книжкой» и «Сложен» открываются как 180°, 110° и 0°.
- У MacBook Air и MacBook Pro есть ползунок «Раскрытие крышки» от 0° (закрыт) до 135°. По умолчанию 110°, как в файлах моделей.
- Экран пустой, пока вы не загрузите файл. Нажмите «Загрузить изображение» или перетащите PNG, JPG, WebP, MP4 либо WebM в рабочую область.
- Видео на экране проигрывается прямо в превью. В разделе «Экран» появляется блок «Видео»: пуск и пауза, зацикливание отрезка, начало и конец, скорость и звук. Зацикливание работает по обрезанному отрезку, а не по всему файлу.
- Картинку можно вставить из буфера обмена: Ctrl+V в любом месте редактора. Из Figma копируйте фрейм как картинку — Shift+⌘+C (Copy as PNG). Обычное ⌘C кладёт в буфер слой Figma, а не изображение; редактор подскажет, что делать.
- Под карточкой экрана есть поле «Ссылка на сайт или фрейм Figma». Вставьте адрес сайта, например `example.com`, и нажмите Enter. Для телефонов сайт откроется в мобильной версии с user agent iPhone и плотностью 3×, для iPad, Mac и Pro Display XDR — в настольной версии с плотностью 2×; у iPad ширина страницы 1032 точки, как в Safari. Снимок первого экрана встанет точно в разрешение экрана выбранной модели, например 1290 × 2788 для iPhone 15 Pro Max. Ссылку можно и просто вставить через Ctrl+V.
- Ссылка на фрейм Figma (правый клик по фрейму → Copy link to selection) рендерится через API Figma сразу в ширину экрана — без растягивания. Для этого нужен `FIGMA_TOKEN`, см. раздел о деплое. Локально переменную можно положить в `.env.local`.
- Локально для снимков сайтов используется Chromium из Playwright (`npx playwright install chromium`), а если его нет — установленные Chrome или Edge. Путь к браузеру можно задать переменной `CHROME_PATH`.
- Снимок близкой к экрану пропорции заполняет экран целиком, кадр другой пропорции вписывается целиком. При смене модели или сгиба вписывание пересчитывается под новый экран. Режим можно сменить в разделе «Экран».
- При запуске выбран ракурс «Прямо». Другие ракурсы находятся в компактном меню слева сверху; «Горизонтально» доступен для телефонов и iPad. Перетаскивайте модель, чтобы свободно вращать камеру.
- Положение устройства в кадре меняется инструментами слева: «Перемещение» (W), «Вращение» (E) и «Масштаб» (R). У вращения — кольца вокруг модели; у масштаба — одна ручка, меняющая размер устройства равномерно. Камера при этом продолжает вращаться перетаскиванием мимо ручек. Shift во время жеста включает шаг: 15° для поворота и 5 % для масштаба. Esc возвращает устройство туда, где жест начался. Целый жест отменяется одним Ctrl+Z.
- Те же значения — в разделе «Положение»: сдвиг по X, Y, Z в сантиметрах модели, поворот по трём осям и масштаб. «Сбросить положение» возвращает устройство в центр. Крен камеры остаётся настройкой камеры и применяется поверх положения.
- В разделе «Экран» настройте вписывание, масштаб и сдвиг изображения. Если вырез камеры уже есть на скриншоте, отключите его в редакторе. Переключатель появляется у экранов с вырезом: у iPhone, Galaxy и внешнего экрана Duo.
- В разделе «Фон» выберите тип фона: цвет, градиент, готовый пресет или прозрачный.
- В разделе «Свет» выберите одну из трёх схем: «Мягкий», «Студийный» или «Контровой». Направление меняется на площадке, яркость — ползунком или числом; точное значение направления и экспозиция находятся в «Дополнительно».
- В разделе «Тень» выберите вид тени: «Мягкая», «Контактная» — устройство почти касается фона, «Парящая» — далеко от фона и размыта, «Длинная» — уходит вбок, «Резкая». Плотность, мягкость, расстояние до фона и длину можно менять вручную — тогда вид становится «Своим». Цвет тени по умолчанию — тёмный оттенок фона; «Свой» цвет выбирается палитрой или кодом HEX. Тень сохраняется в альфа-канале прозрачного PNG.
- «Готовые» — библиотека из двенадцати мягких фонов четырёх групп. Переключатель «Движение» заставляет цветовые пятна медленно ходить по орбитам; скорость настраивается отдельно. Движение выключается само при системной настройке «уменьшить анимацию».
- Своё фото или видео на фон загружается карточкой в конце раздела «Фон» — она видна при любом выбранном типе, отдельно переключаться не нужно. Файл ложится «по заполнению», видео зацикливается без звука. Кнопка «Убрать свой фон» возвращает прежний тип.
- В режиме «Изображение» нажмите «Скопировать PNG» или Ctrl+Shift+E: мокап без фона попадёт в буфер обмена, его можно сразу вставить в Figma через Ctrl+V. Фон сцены исключается только из скопированной картинки, в проекте он остаётся; тень сохраняет свой цвет. При первом копировании браузер спросит разрешение на уведомления: с ним об успехе сообщит уведомление системы, без него — сообщение в редакторе. Файл при копировании не скачивается.
- «Скачать PNG» сохраняет кадр файлом. Прозрачный фон сохраняется в альфа-канале PNG. Максимальный размер — 3840 пикселей по длинной стороне.

Итоговый кадр — прямоугольник в центре рабочей области; над ним подписаны формат и размер экспорта. Пока кадр помещается целиком, он стоит по центру; увеличенный кадр можно двигать до его краёв, но не увести за рабочую область. «Уместить кадр» (Shift+1 или F) возвращает целый вид. Масштаб и перемещение рабочей области не меняют кадр экспорта. Масштаб меняется плавно и мягким шагом: один щелчок колеса — примерно 1,16 раза. При наезде превью перерисовывается плотнее, поэтому модель остаётся чёткой; на экспорт это не влияет — он всегда считается в выбранном разрешении.

## Анимация

- В режиме «Анимация» внизу открывается таймлайн: слева дорожки «Камера» и устройство, справа шкала времени и ключи. Длительность ролика — от 0,5 до 60 секунд, поле рядом с текущим временем.
- Поставьте курсор времени и поверните камеру или устройство. Первое изменение свойства не в начале ролика ставит два ключа: прежнее значение в начале и новое под курсором. Дальше изменения анимированного свойства обновляют ключ под курсором или ставят новый.
- Ромб у поля в панели показывает ключ: пустой — свойство не анимировано, контур — анимировано, заливка — ключ под курсором. Щелчок ставит или убирает ключ. Ромб у дорожки «Камера» или устройства записывает текущее положение всех их свойств.
- Ключ перетаскивается мышью; Shift прилипает к курсору и другим ключам. Рамкой на таймлайне можно выделить несколько ключей, Shift добавляет к выбору. Нажатие на название дорожки выбирает все её ключи. Группа перемещается с сохранением интервалов и удаляется клавишей Delete. Стрелка у дорожки раскрывает её свойства; щелчок по названию свойства открывает его поле в панели.
- Щелчок по полосе между ключами выбирает участок, Shift добавляет другие участки. В категории «Анимация» выбранным участкам одним действием назначается кривая: «Линейно», «Плавно», «Разгон», «Торможение», «С перелётом»; остальные — в «Все кривые».
- Курсор времени перетаскивается по шкале, над ним показывается время. С Shift курсор прилипает к ближайшему ключу. Space — пуск и пауза, Home и End — начало и конец ролика.
- «Движение» над холстом предлагает три исходных движения камеры и четырнадцать дополнительных вариантов поворота, наезда, входа, сдвига и акцента. Щелчок показывает движение с курсора времени; «Применить» ставит обычные ключи камеры, их можно править и отменить одним Ctrl+Z. Движение подстраивается под габариты устройства; при применении ортографическая камера переключается на перспективу.
- Кнопка «Добавить аудио» создаёт одну дорожку из локального файла. Дорожку можно двигать по времени, обрезать с обоих концов, менять громкость и выключать звук. Аудио сохраняется в проекте и звучит при воспроизведении и экспорте видео.
- «Размытие движения» смазывает быстрые повороты и наезды. Сила — доля длительности кадра, в течение которой открыт затвор. В превью на паузе размытие считается по 12 подкадрам, во время воспроизведения — по 5, в экспорте — по 16.
- Видео на экране, своё видео на фоне и движение готового фона в анимации идут по таймлайну. Ролик без ключей при загрузке видео на экран получает длительность видео; кнопка «Длина ролика по видео» подгоняет её позже.

### Экспорт анимации

«Экспортировать» или Ctrl+Shift+E в режиме анимации открывает окно «Экспорт анимации». Запись начинается только кнопкой «Экспортировать» в окне.

| Формат | Где открывать | Прозрачность |
| --- | --- | --- |
| WebM (VP9) | Сайты и веб-презентации в Chrome, Edge и Firefox | Да |
| MP4 (H.264) | Почти везде | Нет |
| Кадры PNG в ZIP | Монтажные программы, которые импортируют последовательность изображений | Да |

- «Прозрачный фон» убирает фон сцены, включая своё фото или видео на фоне, только из результата. Тень остаётся. Для MP4 переключатель недоступен: формат не хранит прозрачность.
- Прозрачность WebM проверена записью и разбором готового файла в Edge: альфа-канал сохраняют только кодеки VP9 и VP8. H.264 и AV1 в браузере его отбрасывают, кодирование WebCodecs с альфой Edge не поддерживает.
- WebM и MP4 пишутся в реальном времени: ролик на пять секунд пишется пять секунд, во время записи не переключайтесь на другую вкладку. Время кадра берётся по часам, поэтому при медленном рендере движение не замедляется, а теряет часть кадров. Кадры PNG считаются покадрово и точно, но дольше.
- Аудиодорожка входит в WebM или MP4, если она включена. Последовательность PNG сохраняется без звука.

## Аналитика

Microsoft Clarity подключена к проекту `yy55bnhv3e`. Скрипт загружается через `next/script` после гидратации только при `VERCEL_ENV=production`; localhost и preview-деплои не отправляют настоящую аналитику. Дополнительные пакеты и секретные ключи не нужны.

События в Clarity:

| Событие | Значение |
| --- | --- |
| `editor_active` | Пользователь взаимодействует с видимым редактором: мышь, клавиатура, колесо, вставка или перетаскивание. Не чаще одного события в календарную минуту. |
| `mockup_export_png` | PNG успешно сформирован и передан браузеру на скачивание. |
| `mockup_copy_png` | PNG без фона записан в буфер обмена. |
| `mockup_export_video` | Анимация успешно экспортирована в WebM, MP4 или кадры PNG и передана браузеру на скачивание. |

**DAU:** в Dashboard выбрать ровно один день, применить фильтр Smart events → `editor_active` и смотреть **Unique users**, а не число событий или сессий. Для дневного ряда повторять срез по каждому дню в одном часовом поясе. Unique users за 7 дней — это недельная аудитория, её нельзя выдавать за DAU или делить на 7 как точный средний DAU. Браузеры и блокировщики влияют на точность обезличенного счётчика; один человек на разных устройствах может считаться несколько раз.

Параметры событий не содержат файлы, имена, вставленные ссылки или персональные идентификаторы. Области с загруженными изображениями, файлами и предпросмотром сайта дополнительно помечены `data-clarity-mask`. Согласие пользователя не подменяется программно: действует Consent Mode проекта Clarity; для полного сбора из EEA/UK/CH нужно настроить передачу согласия через CMP или Consent API.

Документация: [события и маскирование](https://learn.microsoft.com/en-us/clarity/setup-and-installation/clarity-api), [фильтры](https://learn.microsoft.com/en-us/clarity/filters/clarity-filters), [Consent Mode](https://learn.microsoft.com/en-us/clarity/setup-and-installation/consent-mode).

## UI

Используются компоненты [Fluid Functionalism](https://www.fluidfunctionalism.com/): Select, TabsSubtle, Button, fluid hover, spring-переходы и система поверхностей. Шрифт Inter Variable хранится локально. Тёмная и светлая темы используют серую палитру. Переключатель находится рядом с сохранением проекта и справкой; выбор сохраняется в браузере. При первом запуске включена тёмная тема. Тема интерфейса не меняет фон сцены и PNG. Класс темы выставляется до первой отрисовки, поэтому светлая тема не моргает тёмной при загрузке, а при переключении палитра перетекает за 160 мс.

- Панель инструментов и панель масштаба работают на fluid hover: подсветка переезжает к ближайшей к курсору кнопке, а клик в зазор попадает в подсвеченную.
- Подложка выбранного варианта в переключателях и в форматах кадра — один элемент на группу; при смене выбора она переезжает пружиной `spring.moderate`.
- Нажатие на «Скачать мокап» сжимает поверхность на один пиксель с каждой стороны вместо масштабирования: широкая кнопка от масштаба искажалась бы по горизонтали сильнее, чем по вертикали.

Применены рекомендации скилла Emil Kowalski по обратной связи, прерываемости и reduced motion: при `prefers-reduced-motion` переходы выключаются, а содержимое остаётся на своих местах.

Сведения об авторах моделей и используемых источниках — в `THIRD_PARTY_NOTICES.md`.
