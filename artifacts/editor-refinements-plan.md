# Доработки редактора после проверки — 20 октября 2026

Пользователь проверил реализованные итерации 1–8 и разрешил следующий цикл: сначала крупные задачи, затем локальные исправления. Текущая база уже содержит анимацию, экспорт и манипуляторы; прежний план не выполняется повторно.

| Итерация | Размер | Задачи и критерий готовности |
|---|---|---|
| R1. Выделение и редактирование таймлайна | Крупная | Рамка мышью выделяет ключи нескольких строк; Shift дополняет выбор; нажатие на имя слоя выбирает все его ключи. Несколько участков выбираются с Shift, easing применяется одним действием ко всему выбору. Группу можно переместить и удалить, отменить одним шагом. Сдвиг соответствует курсору при разном масштабе и прокрутке; интервалы группы сохраняются у краёв. |
| R2. Аудио | Крупная | Одна дорожка: файл, положение по времени, начало/конец исходника, громкость, выключение звука, синхронное воспроизведение и звук в экспорте видео. Сохранение проекта, отмена, ошибки файлов. Пользователь подтвердил одну дорожку для первой версии. |
| R3. Разделы сайдбара и контекст выбора | Крупная | Навигация по категориям по второму референсу вместо длинного списка. При выборе ключей/участков видны только применимые параметры анимации. При возврате к сцене доступны прежние настройки. Выбор свойства показывает его настройки. Свет по дополнительному референсу: выбор схемы, площадка направления, яркость с числом; реальные режимы Environment/Directional сверить с рендером до добавления переключателей. |
| R4. Манипуляторы | Средняя | Согласовать линии, ручки и состояния с нейтральным интерфейсом; сохранить понятность осей и удобные зоны захвата. Scale — одна ручка и равномерный размер по подтверждению пользователя. |
| R5. Быстрые действия и исправления | Малая | Пресеты камеры перенести на верхнюю панель холста рядом с ракурсами. Space устойчиво запускает/останавливает анимацию после работы с холстом; не мешает вводу и перетаскиванию с пробелом. Проверить темы, размеры окна и весь сценарий. |

Порядок: R1 → R2 → R3 → R4 → R5. Исправление переноса входит в R1: оно необходимо для группового редактирования. Каждая итерация заканчивается проверкой сценариев; завершённые шаги отмечаются ниже.

## Границы

- Механика камеры остаётся без изменений: пользователь просил пока только записать наблюдение.
- Масштабирование сохраняет пропорции устройства, без растягивания по одной оси.
- Источники аудио — локальные файлы; отдельная библиотека музыки и многодорожечный микшер не запрошены.
- Новые зависимости и смена стека не требуются по текущей оценке.

## Наблюдения до правок

- `Timeline.startKey` передаёт абсолютный сдвиг жеста в `moveSelectedKeys`, который считает новую анимацию от снимка на старте. `Timeline.shifted` затем снова прибавляет тот же сдвиг к уже изменённым временам при отрисовке. Это подтверждает причину двойного визуального перемещения; проверка поведением добавляется в R1. Уверенность: 95%.
- Старое выделение хранит только один ключ/один участок; имя слоя — обычный текст. Потребуются выбор множества ключей/участков и операции по устойчивым идентификаторам.
