# iPhone Mockup Studio — исходный план первой версии

План сохранён как история исходного запроса. Позднее пользователь предоставил модели iPhone 15 и 18, выбрал Fluid Functionalism, тёмную и светлую темы и деплой на Vercel. Актуальное состояние — в `project-state.md`, запуск и деплой — в `README.md` в корне проекта.

## Подтверждено пользователем

- Локальное приложение в браузере, без регистрации.
- Один чёрный iPhone 16 Pro в сцене.
- Пользователь загружает изображение на экран и свободно выбирает ракурс.
- Экспорт PNG, включая прозрачный фон, до 3840 пикселей по длинной стороне.
- Первый референс задаёт структуру редактора: большое превью и панель справа.
- Второй референс задаёт желаемую выразительную перспективу.
- UI и взаимодействия реализуются с учётом скилла Emil Kowalski.

## Реализация

1. Next.js с App Router, React, TypeScript strict и Tailwind CSS. Серверный корневой layout; редактор и WebGL — клиентский компонент. Three.js отвечает за настоящую 3D-сцену. Работа с изображениями и рендеринг выполняются локально.
2. Тёмный редактор, панель справа, компактная верхняя строка, настройки без лишних переходов. Понятные подписи на русском. Быстрая обратная связь на нажатия, видимый фокус, управление клавиатурой, поддержка reduced motion.
3. Загрузка PNG/JPEG/WebP через выбор файла и перетаскивание. Заполнение или вписывание экрана, масштаб и смещение изображения. Переключатель Dynamic Island, чтобы не дублировать его на готовом скриншоте.
4. Камера: перспектива и ортографический режим, фокусное расстояние, дистанция, наклон, поворот и крен; перемещение кадра. Управление мышью и числовыми полями. Пресеты: прямо, три четверти, низкий ракурс с сильной перспективой, сверху, горизонтально, сзади. Независимый сброс камеры.
5. Освещение: несколько студийных схем, интенсивность, экспозиция и отражения. Фон: цвет, градиент или прозрачность. Форматы кадра 16:9, 4:3, 1:1, 4:5, 9:16.
6. Экспорт PNG в выбранном формате и разрешении: без панели, сетки и элементов управления. Во время экспорта показывается состояние выполнения; ошибки сообщаются явно. Прозрачность сохраняется в альфа-канале.

## Источник модели

Исходная ссылка: https://sketchfab.com/3d-models/iphone-16-pro-c11a00f7959e47fd95ae95ccf94134ea

Публичный API Sketchfab на момент проверки сообщает `isDownloadable: false`. Файл исходной модели не получен.

Найдена альтернатива iPhone 16 Pro от tranminhluan: https://sketchfab.com/3d-models/iphone-16-pro-96be8c7e49fa4f949855db3e7f2e64e0

API сообщает `isDownloadable: true`, CC Attribution и 49 568 треугольников. Перед интеграцией нужно получить файл и проверить геометрию экрана, материалы и ориентацию. Получение через доступный официальный способ; указать автора в поставке. Найденная карточка сама по себе не означает, что файл уже скачан или пригоден для подстановки экрана.

## Зависимости, требующие подтверждения

Основные: next, react, react-dom, three, lucide-react.

Разработка: typescript, @types/node, @types/react, @types/react-dom, @types/three, tailwindcss, @tailwindcss/postcss, babel-plugin-react-compiler. Проверка браузерных сценариев — Playwright, если доступная среда не предоставляет готовый runtime.

База данных, аккаунты и внешние сервисы для работы редактора не требуются.

## Критерии проверки

- Проверка TypeScript и production build проходят.
- Изображение корректно ориентировано и ограничено формой экрана при смене ракурса.
- Мышь, пресеты и числовые настройки управляют одной и той же камерой без скачков и рассинхронизации.
- Режим сильной перспективы заметно увеличивает ближний торец.
- Экспорт имеет выбранные размеры и совпадает с кадром превью.
- PNG с прозрачным фоном содержит прозрачные пиксели вне телефона.
- Повторная загрузка изображения, сброс, ошибки файла и повторный экспорт работают.
- Основные действия доступны с клавиатуры; панель помещается на обычном экране ноутбука.

## Текущий статус
