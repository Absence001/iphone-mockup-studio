## Clarity и DAU

Пользователь выбрал Microsoft Clarity, предоставил код проекта `yy55bnhv3e` и отдельно попросил DAU. Подключение разрешено вместе с событиями экспорта и публикацией в production.

- Скрипт подключён через `next/script` с `afterInteractive` только при `VERCEL_ENV=production`; новых зависимостей нет.
- `editor_active` отправляется при настоящем взаимодействии с видимым редактором, не чаще одного раза в календарную минуту. DAU читается как Unique users за один день с фильтром этого события, а не как число отправленных событий.
- `mockup_export_png` и `mockup_export_video` отправляются после формирования файла и запуска скачивания. Отмену сохранения в диалоге браузера приложение определить не может.
- В событиях нет пользовательских файлов, ссылок или имён. Области с пользовательскими вложениями маскируются через `data-clarity-mask`. Программного согласия от имени посетителя нет.
- Проверка TypeScript и production-сборка с `VERCEL_ENV=production` прошли. Отдельный браузерный сценарий проверил активность/новый день, успешный и неуспешный PNG, а также работу редактора при ошибке стороннего скрипта. Событие видео подключено в успешную ветку существующего экспорта; отдельный полный прогон записи видео в этой итерации не выполнялся.

Инструкция чтения DAU и названия событий находятся в README, раздел «Аналитика».

## Реализовано

- Локальный редактор Next.js / React / Three.js, без регистрации. Один телефон со скриншотом, PNG до 3840 пикселей по длинной стороне и прозрачность.
- Пользовательские GLB: iPhone 15 Pro Max Black; iPhone 18 Pro Max Black, Glacier, Burgundy, Silver. Названия взяты из метаданных файлов. Источники и лицензии описаны в `THIRD_PARTY_NOTICES.md`.
- 15 октября 2026 добавлены iPhone Duo (Star White, сгиб «Раскрыт / Книжкой / Сложен»), Galaxy S26 Ultra, MacBook Pro 14″ и Pro Display XDR. Модели выбраны на Sketchfab, пользователь скачал их сам. Студийного дисплея с подходящей лицензией не нашлось: бесплатная модель Studio Display распространяется только для некоммерческого использования (CC BY-NC), поэтому взят Pro Display XDR. Для Pixel моделей свежих поколений нет.
- UI на компонентах Fluid Functionalism. Компактные меню ракурса, модели и цвета; вкладки камеры, экрана и сцены. Свет: три варианта и яркость, дополнительные параметры свёрнуты.
- Навигация рабочей области, горячие клавиши, отмена/повтор, сохранение и открытие проекта со встроенным изображением. Масштаб рабочей области не влияет на экспорт.
- Стартовый ракурс и сброс камеры — «Прямо». Остальные пресеты сохраняют перспективную камеру.
- Тёмная тема по умолчанию, светлая по кнопке рядом с сохранением и справкой. Выбор сохраняется в localStorage; тема не входит в настройки проекта и не меняет PNG.
- Фавикон: PNG пользователя подключён через `public/favicon.png` и `metadata.icons.icon` в `src/app/layout.tsx`.

## Исправленная ошибка

Обычный inline `<script>` в `src/app/layout.tsx`, добавленный для восстановления темы, вызвал предупреждение React при горячем обновлении. Его удалили. Браузерный сценарий проверяет отсутствие ошибок React и сохранение темы после перезагрузки.
