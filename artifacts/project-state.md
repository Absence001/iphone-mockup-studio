# Состояние проекта

Дата: 15 октября 2026.

## Текущий запрос и следующий шаг

После работы по дизайну пользователь дал команду «комит и пуш» и уточнил, что будет деплоить на Vercel. Разрешены создание нового приватного репозитория и отправка текущего проекта. Первоначальный remote указывал на `Absence001/codex-git-test`; приложение в него не отправляли.

Создан приватный репозиторий: https://github.com/Absence001/iphone-mockup-studio. Основная ветка — `main`, remote — `origin`. Старый remote сохранён как `previous-origin`.

## Реализовано

- Локальный редактор Next.js / React / Three.js, без регистрации. Один телефон со скриншотом, PNG до 3840 пикселей по длинной стороне и прозрачность.
- Пользовательские GLB: iPhone 15 Pro Max Black; iPhone 18 Pro Max Black, Glacier, Burgundy, Silver. Названия взяты из метаданных файлов. Источники и лицензии описаны в `THIRD_PARTY_NOTICES.md`.
- UI на компонентах Fluid Functionalism. Компактные меню ракурса, модели и цвета; вкладки камеры, экрана и сцены. Свет: три варианта и яркость, дополнительные параметры свёрнуты.
- Навигация рабочей области, горячие клавиши, отмена/повтор, сохранение и открытие проекта со встроенным изображением. Масштаб рабочей области не влияет на экспорт.
- Стартовый ракурс и сброс камеры — «Прямо». Остальные пресеты сохраняют перспективную камеру.
- Тёмная тема по умолчанию, светлая по кнопке рядом с сохранением и справкой. Выбор сохраняется в localStorage; тема не входит в настройки проекта и не меняет PNG.

## Исправленная ошибка

Обычный inline `<script>` в `src/app/layout.tsx`, добавленный для восстановления темы, вызвал предупреждение React при горячем обновлении. Его удалили. В последующей итерации дизайна раннее восстановление темы подключено через `next/script` с `beforeInteractive`; компонент переключателя считывает уже установленный класс темы. Браузерный сценарий проверяет отсутствие ошибок React и сохранение темы после перезагрузки.

## Проверка

Перед первой отправкой прошли `npm run typecheck`, `npm run build` и полный `npm test` — 7 сценариев, включая все модели, PNG 4K и прозрачность, темы, навигацию, отмену, проекты и адаптивность. Проверки браузера выполнены в Microsoft Edge через Playwright. Новый сценарий исключает известный ответ 404 на запрос браузера к отсутствующему `/favicon.ico`; остальные ошибки консоли и необработанные исключения приводят к падению проверки. Дополнительно проверены регистр путей импортов и наличие Linux-пакетов в lock-файле для сборки на Vercel.

Скриншоты: `artifacts/previews/studio-dark.png` и `artifacts/previews/studio-light.png`. Дев-сервер доступен на `http://127.0.0.1:3000`.

## Решения пользователя

- Исходный план с iPhone 16 заменён фактическими моделями 15 и 18 из файлов пользователя.
- Первоначальный зелёный интерфейс заменён нейтральной палитрой и Fluid Functionalism по прямому запросу.
- Тёмная тема возвращена вместе со светлой; стартовый ракурс изменён на «Прямо».
- После завершения работы по дизайну пользователь возобновил создание нового приватного репозитория, commit и push. Цель деплоя — Vercel; сам деплой выполняет пользователь. Node.js 24 закреплена в `package.json` и `.nvmrc`, параметры импорта указаны в README.
